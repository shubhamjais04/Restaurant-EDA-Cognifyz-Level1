# 🍽️ Restaurant Data Analysis — Level 1

Exploratory data analysis on a global restaurant dataset covering data preprocessing, statistical analysis, geospatial visualization, and cuisine insights across 15 countries and 146 cuisines.

---

## 📌 Project Overview

This project performs a comprehensive exploratory analysis on a real-world restaurant dataset. The goal is to uncover patterns in restaurant ratings, cuisine popularity, geographic distribution, and service availability — transforming raw data into meaningful business insights.

---

## ✨ What's Covered

### Task 1 — Data Exploration & Preprocessing
- 🔍 Dataset shape identification — rows, columns, data types
- 🩹 Missing value detection and handling
- 🔄 Data type conversion and formatting
- 📊 Target variable distribution analysis (`Aggregate Rating`)
- ⚖️ Class imbalance identification

### Task 2 — Descriptive Analysis
- 📐 Statistical measures — mean, median, standard deviation for numerical columns
- 🌍 Distribution of categorical variables — Country Code, City, Cuisines
- 🏆 Top cuisines and cities by restaurant count
- 💡 Key business insights from the data

### Task 3 — Geospatial Analysis
- 🗺️ Restaurant location visualization using latitude and longitude
- 🌐 Distribution of restaurants across cities and countries
- 📈 Correlation between restaurant location and rating

---

## 📊 Dataset

- **Records:** 9,551 restaurants
- **Countries:** 15
- **Cuisines:** 146
- **Target Variable:** Aggregate Rating (0–5)
